# آپلودساز (Uploader)

آپلودساز شخصی با لینک اشتراک‌گذاری **منقضی‌شونده** و **رمزدار**.
ساخته‌شده با Next.js، React، TypeScript و کامپوننت‌های [PersianLabs/ui](https://ui.persian-labs.ir) (راست‌به‌چپ، فونت وزیرمتن، تقویم شمسی).

## امکانات

- آپلود تکه‌ای (۵ مگابایت) با تلاش مجدد خودکار برای هر بخش، مناسب هاست اشتراکی
- لینک اشتراک با زمان انقضا (پیش‌تنظیم یا تاریخ و ساعت شمسی دلخواه)
- رمز لینک دانلود (scrypt) و محدودیت ۵ تلاش اشتباه (قفل ۱۵ دقیقه‌ای)
- فشرده‌سازی ZIP با رمز اختیاری داخل آرشیو (AES-256)
- نام تصادفی عددی یا نام دلخواه
- دانلود قابل ادامه (HTTP Range)
- ویرایش نام / انقضا / رمز، لغو لینک، ساخت لینک جدید، حذف
- پاک‌سازی خودکار فایل‌های منقضی و آپلودهای نیمه‌تمام
- سهمیهٔ فضا با نوار مصرف

## اجرا

```bash
cp .env.example .env     # ADMIN_USER و ADMIN_PASS را تنظیم کنید
npm install
npm run build
npm start                # node server.js  (پورت پیش‌فرض ۳۰۰۰)
```

برای توسعه: `npm run dev`.

## متغیرهای محیطی

| نام | توضیح |
| --- | --- |
| `ADMIN_USER`, `ADMIN_PASS` | **الزامی** — مشخصات ورود به پنل |
| `SESSION_SECRET` | اختیاری — کلید امضای نشست |
| `QUOTA_GB` | اختیاری — سهمیهٔ فضا (پیش‌فرض ۴٫۵) |
| `DATA_DIR` | اختیاری — محل فایل‌ها و `db.json` (پیش‌فرض `./data`) |

## استقرار روی cPanel

1. در **Setup Node.js App** یک برنامه بسازید (Node 20 یا بالاتر) و *Application startup file* را `server.js` بگذارید.
2. کد را آپلود کنید و متغیرهای محیطی بالا را در همان صفحه تنظیم کنید.
3. `NPM Install` را بزنید، سپس `npm run build` را اجرا کنید (از ترمینال cPanel).
4. برنامه را Restart کنید.

`DATA_DIR` را بیرون از پوشهٔ پروژه بگذارید تا با استقرار مجدد پاک نشود.

## ساختار

```
app/                 صفحه‌ها و API (Route Handlers)
  api/               ورود، آپلود تکه‌ای، مدیریت فایل‌ها
  d/[token]/         صفحهٔ دانلود عمومی، تأیید رمز و دانلود فایل
components/ui/       کامپوننت‌های PersianLabs/ui
components/dashboard پنل مدیریت
lib/server/          دیتابیس JSON، احراز هویت، ZIP، پاک‌سازی
lib/client/          فرمت فارسی، کلاینت API، آپلودر
server.js            ورودی استقرار (cPanel / npm start)
```
